# Status

Current implementation state: factual reports, no roadmap.

- `implementation-status.md`: what is built, what is tested, per-plugin and
  per-crate coverage.
- `implementation-gaps.md`: documented behaviour that the runtime does not
  yet implement (drift ledger).

The evaluation is finished: the final batches of the Raspberry Pi 5, Jetson
and x86 hosts are approved in
[`eval/final-batches.json`](../../eval/final-batches.json), and their results
are reported in the thesis.

Aspirational items live in the repo-root `ROADMAP.md`; open work is tracked
in GitHub issues.
