# Status

Current implementation and evaluation state: factual reports, no roadmap.

- `implementation-status.md`: what is built, what is tested, per-plugin and
  per-crate coverage.
- `implementation-gaps.md`: documented behaviour that the runtime does not
  yet implement (drift ledger). Every RFC / ADR / architecture chapter with
  an aspirational banner points here; closed entries are archived.
- `canonical-readiness.md`: what the final campaign still needs, and the
  current claim boundaries.
- `rpi5-canonical-transition.md`: decision record for the Raspberry Pi 5
  4 GB host, native eKuiper 2.1.5 and the canonical CPU allocation.

Aspirational items live in the repo-root `ROADMAP.md`; open work is tracked
in GitHub issues.

The pre-final readiness and progress logs, the old planning scratchpads and
the Phase 0 session recipes are archived under
[`docs/history/`](../history/README.md).
