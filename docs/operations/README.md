# Operations

How-to guides for running WAFER — installing, configuring, wiring to external
systems, and observing the runtime.

- `getting-started.md` — install, build, and run your first pipeline.
- `configuration.md` — configure engine, error policy, nodes, edges, API,
  metrics, and registry sections.
- `mqtt-setup.md` — set up a local Mosquitto broker for MQTT source/sink
  development.
- `registry.md` — publish, pull, and cache Wasm components via OCI registries.
- `observability.md` — Prometheus metrics and structured logging.
- `dependencies.md` — pinned toolchain and third-party crate versions.
