# Specifications

This directory contains detailed specifications for WAFER features and components.

## Spec Structure

```
specs/
├── README.md              # This file
└── <feature-name>/
    └── spec.md            # Feature specification
```

## Creating Specs

Use the OpenSpec workflow:

```bash
# 1. Discuss and plan with the OpenSpec Architect
# 2. Run /openspec.proposal to generate formal specs
# 3. Implement via /openspec.apply-change
```

## Relationship to Existing Documentation

This project has extensive existing documentation in `docs/`:

| Document | Purpose | Use For |
|----------|---------|---------|
| [docs/SPEC.md](../docs/SPEC.md) | **Authoritative specification** | Core architecture, WIT contracts, evaluation plan |
| [docs/MVP.md](../docs/MVP.md) | Implementation status | What's done vs. remaining work |
| [docs/adr/](../docs/adr/) | Architecture decisions | Historical context, rationale |

**New specs in this directory** are for:
- Features not yet covered in SPEC.md
- Detailed implementation plans for MVP gaps
- Experimental features being explored

## Spec Template

```markdown

- R2: ...

### Approach
Description of the implementation approach.

### WIT Changes (if applicable)

```

### Configuration Changes (if applicable)
```toml

```

```
