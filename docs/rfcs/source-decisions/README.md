# Source Decision Archive

This directory contains bit-for-bit copies of the deleted `docs/decisions/*`
source documents that were migrated during the 2026-07-18 documentation
refactor.

These files are **historical provenance**, not active design sources. Active
long-form decisions live one level up as RFCs (`../RFC-001-wit-contracts.md`
through `../RFC-011-doc-refactor.md`); short executive decision records live in
`../../adr/`; implementation drift is tracked in
`../../status/implementation-gaps.md`.

The migration completeness audit is
[`../../status/migration-audit.md`](../../status/migration-audit.md). It maps
each concrete decision row from these source documents to its successor RFC,
ADR, status/workflow document, or implementation-gap entry.
