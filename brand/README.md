# WAFER brand assets

These are the canonical WAFER identity assets used across the project. Keeping
local copies makes this repository README self-contained.

| File | Use |
| --- | --- |
| [`logo.svg`](logo.svg) | Standalone WAFER mark. |
| [`wafer-lockup.svg`](wafer-lockup.svg) | Mark, wordmark, and tagline on light backgrounds. |
| [`wafer-lockup-dark.svg`](wafer-lockup-dark.svg) | Mark, wordmark, and tagline on dark backgrounds. |
| [`wafer-runtime-overview.svg`](wafer-runtime-overview.svg) | Runtime overview illustration for the repository README. |

The lockups have transparent backgrounds and outlined text, so they do not
require installed fonts. Use the light and dark files together in a `<picture>`
element when the display supports color-scheme selection.

The identity palette is accent `#c2410c`, accent-dark `#a1350a`, ink `#1a1613`,
paper `#faf7f2`, lower-layer orange `#d9703f`, and light orange `#ecb392`.
The dark lockup uses muted text `#b3a89b`. The runtime overview uses that
palette plus the neutral panel colors from the canonical documentation theme.
