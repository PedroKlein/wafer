# Architecture

arc42-lite architecture views for WAFER. Each file corresponds to one arc42
section (goals & constraints, solution strategy, building blocks, runtime view,
deployment, cross-cutting concepts, quality requirements, risks, comparators)
plus a one-page vision document at `00-vision.md`.

These documents describe **current reality** only — aspirational or roadmap
items live in the repo-root `ROADMAP.md`. Long-form rationale for the
decisions summarised here lives in `../rfcs/`, and short Nygard-style
decision records live in `../adr/`.
