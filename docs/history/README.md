# Archive

> **Archived, not current.** Everything under `docs/history/` is a historical
> record. Do not use it for decisions, commands, paths or numbers.

This folder keeps plans, logs and session recipes that shaped the code but no
longer describe how the runtime or the evaluation work today. Each file opens
with a banner that names its current replacement. The CI doc checks skip this
folder, so paths inside it may point at files that no longer exist.

| Folder | What it holds |
|---|---|
| `plans/` | Planning scratchpads from the implementation phase |
| `status/` | Pre-final readiness and progress logs split out of `docs/status/` |
| `workflows/` | Phase 0 session recipes |

For the current state, start at [docs/README.md](../README.md) and
[docs/status/](../status/).
